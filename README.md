# Geometry Lunch Seminar — PSU mirror

Backup mirror of the Penn State Geometry Lunch Seminar calendar:

https://anton-petrunin.github.io/geometry-lunch-seminar-PSU/

Original page:

https://calendar.math.psu.edu/math_cal_dept/seminar.php?id=410

## Update

1. Connect to Penn State VPN.
2. Open the seminar page in Firefox.
3. Use the **SingleFile** extension to save:
   - the main seminar page;
   - new or changed linked event pages.
4. Save all files directly into this repository.
5. Run

```bash
./update
```

The script creates `index.html`, rewrites links to the local copies, commits the changes, and pushes them to GitHub.

Do not commit Penn State cookies, passwords, or other authentication data.
